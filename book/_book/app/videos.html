3.1 Introduction videos

In addition to the written introduction and instructions on the FreesearchR app collected in this book, instructional videos are also created and published. These videos are purely intended for educational purposes and are embedded below.

3.1.1 Loadning data

In this video, loading data from several sources are demonstrated.

This includes

  • Choosing data source
  • Evaluate parsing and missing observations
  • Setting missingness threshold and selecting variables

3.1.2 Overview and filters

  • Data overview
  • Browsing observations
  • Applying data filters based on data types and observations

3.1.3 Data evaluation

  • Create table of variable characteristics
  • Evaluate variable correlations
  • Review missingness

3.1.4 Future videos

More videos are planned to cover other options in the app including: data modifications, visuals, exporting code and installing locally to run from R
